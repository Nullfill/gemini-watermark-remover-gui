# Watermark Remover — Desktop Studio (Windows)

نرم‌افزار حرفه‌ای و مدرن برای **تشخیص خودکار و حذف واترمارک و لوگوهای ثابت (مانند لوگوی درخشش Google Gemini / Veo)** از ویدیوها به همراه رابط کاربری گرافیکی (GUI)، حفظ حداکثری کیفیت، پشتیبانی از نرخ فریم متغیر (VFR)، حفظ تمامی ترک‌های صوتی و زیرنویس‌ها، و توزیع به صورت فایل اجرایی پرتابل ویندوز.

## ویژگی‌های کلیدی
- **رابط کاربری مدرن (PySide6)**: پشتیبانی از کشیدن و رها کردن ویدیو (Drag & Drop)، تم تیره (Dark Theme)، و طراحی روان بدون فریز شدن UI.
- **ویرایشگر تعاملی پیش‌نمایش**: امکان مشاهده فریم، کلیک و جابجایی دستی کادر قرمز رنگ واترمارک، تغییر اندازه با دستگیره‌های گوشه، و دکمه‌های پیش‌تنظیم ۴ گوشه (Top-Left, Top-Right, Bottom-Left, Bottom-Right).
- **سه روش حذف واترمارک**:
  1. **AI Inpaint (ProPainter)**: بازسازی بافت پشت واترمارک بر اساس حرکت فریم‌های مجاور بدون تار کردن تصویر (پیش‌فرض).
  2. **Delogo**: درون‌یابی پیکسل‌های مرزی توسط FFmpeg (آنی و مناسب پس‌زمینه‌های یکنواخت).
  3. **Crop**: بریدن نوار حاوی واترمارک و بازگرداندن مقیاس (آنی و تمیز).
- **مدیریت نرخ فریم متغیر (VFR Exact PTS)**: استخراج و بازسازی دقیق تایم‌استمپ‌های PTS فریم به فریم از ویدیوی ورودی؛ جلوگیری قطعی از ناهماهنگی صدا و تصویر (Audio-Video Sync Drift).
- **حفظ تمامی استریم‌ها**: حفظ تمام ترک‌های صوتی اصلی، زیرنویس‌ها، چپترها و متادیتا با استفاده از نگاشت صریح استریم‌ها (`-map`).
- **تشخیص HDR و رنگ**: بررسی و حفظ متادیتای رنگ (`color_primaries`, `color_trc`, `colorspace`) و اعلام هشدار در صورت بارگذاری ویدیوی ۱۰ بیتی HDR.
- **نوار پیشرفت واقعی (Progress Bar)**: خواندن اطلاعات لحظه‌ای پردازش از طریق خط لوله FFmpeg (`-progress pipe:1`) و فرآیند گام‌به‌گام هوش مصنوعی، به همراه دکمه Cancel آنی و پاکسازی فایل‌های موقت.
- **عدم بازنویسی فایل کاربر**: ایجاد نام‌های یکتا مانند `video_clean.mp4` یا `video_clean_1.mp4` در پوشه خروجی امن بدون لمس فایل اصلی.

## معماری برنامه
پروژه با ساختار ماژولار و تفکیک کامل لایه‌های Core، GUI و AI طراحی شده است:

```text
WatermarkRemover/
├── app.py                      # نقطه ورود اصلی برنامه رابط گرافیکی (GUI Entry Point)
├── dewatermark.py              # واسط خط فرمانی و اجرای مستقیم (CLI & Backward Compatibility)
├── WatermarkRemover.spec       # فایل مشخصات PyInstaller برای تولید فایل EXE
├── build.bat                   # اسکریپت بیلد اتوماتیک ویندوز (Batch)
├── build.ps1                   # اسکریپت بیلد اتوماتیک ویندوز (PowerShell)
├── requirements.txt            # نیازمندی‌های زمان اجرای برنامه
├── requirements-dev.txt        # نیازمندی‌های توسعه، تست و پکیجینگ
├── ffmpeg/                     # باینری‌های مستقل FFmpeg و FFprobe ویندوز
│   ├── ffmpeg.exe
│   └── ffprobe.exe
├── models/                     # وزن‌های مدل‌های هوش مصنوعی ProPainter
│   ├── ProPainter.pth
│   ├── raft-things.pth
│   └── recurrent_flow_completion.pth
├── output/                     # پوشه پیش‌فرض ذخیره‌سازی ویدیوهای پاکسازی‌شده
├── core/
│   ├── config.py               # مدیریت مسیرها، پایگاه تنظیمات QSettings و تمیزکاری temp
│   ├── logger.py               # ثبت رخدادها در لاگ چرخشی logs/app.log و کنسول
│   ├── ffmpeg_runner.py        # مکان‌یاب خودکار FFmpeg، نظارت بر پردازش، پارسر پیشرفت و Cancel
│   ├── video_info.py           # استخراج متادیتا با ffprobe، تشخیص VFR/HDR و فریم پیش‌نمایش
│   ├── detection.py            # تشخیص پایداری زمانی واترمارک، امتیازدهی گوشه‌ها و برش پنجره
│   ├── models_manager.py       # اعتبارسنجی یکپارچگی فایل‌های مدل و دانلود خودکار با ProgressBar
│   └── processor.py            # ترد پس‌زمینه (QThread) برای اجرای پایپ‌لاین‌های Inpaint، Delogo و Crop
├── propainter/                 # ماژول پالایش‌شده و ادغام‌شده ProPainter (کاملاً بومی و مستقل از Git)
├── ui/
│   ├── theme.py                # تم تیره مدرن و شکیل QSS
│   ├── preview_widget.py       # ویجت تعاملی پیش‌نمایش با کادر جابجاشونده و قابل ریسایز
│   ├── settings_dialog.py      # پنجره تنظیمات کیفیت، CRF، دایرکتوری خروجی و شتاب سخت‌افزاری
│   ├── models_dialog.py        # پنجره دانلود خودکار وزن‌های مدل هوش مصنوعی
│   └── main_window.py          # پنجره اصلی برنامه، Drag & Drop و مدیریت رویدادها
└── tests/
    └── test_all.py             # تست‌های جامع خودکار برای ۱۶ سناریوی مختلف
```

## نحوه اجرای محیط توسعه

### ۱. نصب وابستگی‌ها
پایتون 3.9 تا 3.11 را باز کرده و دستور زیر را اجرا کنید:
```bash
python -m pip install -r requirements.txt
```

### ۲. اجرای برنامه گرافیکی (GUI)
```bash
python app.py
```
یا:
```bash
python dewatermark.py --gui
```

### ۳. استفاده از خط فرمان (CLI)
```bash
# تشخیص خودکار و حذف واترمارک با هوش مصنوعی
python dewatermark.py video.mp4

# ایجاد خروجی با روش Delogo و کیفیت سفارشی CRF 18
python dewatermark.py video.mp4 --method delogo --crf 18

# انتخاب گوشه مشخص (پایین-راست: br، پایین-چپ: bl، بالا-راست: tr، بالا-چپ: tl)
python dewatermark.py video.mp4 --corner br

# خروجی پیش‌نمایش تصویری کادر تشخیص داده شده بدون پردازش ویدیو
python dewatermark.py video.mp4 --preview
```

## ساخت نسخه اجرایی ویندوز (Build Windows Portable EXE)

برای ساخت نسخه پرتابل ویندوز، یکی از اسکریپت‌های آماده را اجرا کنید:

### با PowerShell:
```powershell
.\build.ps1
```

### یا با Command Prompt:
```cmd
build.bat
```

پس از اتمام بیلد، یک پوشه توزیع کامل و آماده استفاده در مسیر زیر ایجاد می‌شود:
```text
dist\WatermarkRemover\
    WatermarkRemover.exe   <-- کافی است روی این فایل دوبار کلیک کنید
    _internal/
    ffmpeg/
    models/
    output/
    temp/
    logs/
    README.md
    LICENSE
```
کاربر نهایی نیازی به نصب پایتون، Git یا هیچ ابزار دیگری ندارد و تنها با اجرای `WatermarkRemover.exe` برنامه باز خواهد شد.

## مدیریت FFmpeg و FFprobe
این نرم‌افزار به هیچ وجه فرض نمی‌کند کاربر ffmpeg را نصب کرده یا متغیر PATH را تنظیم کرده است:
1. برنامه در گام نخست فایل‌های `ffmpeg.exe` و `ffprobe.exe` را مستقیماً از پوشه محلی `ffmpeg/` کنار برنامه می‌خواند.
2. نسخه Bundled قرار داده شده، بیلد رسمی **Gyan.dev FFmpeg 9.0.2 Full Build** تحت مجوز GPLv3 است که قابلیت‌های کامل فیلترهای x264، Delogo و انکودینگ را داراست.
3. در صورت عدم وجود باینری در پوشه برنامه، مسیرهای WinGet و System PATH بررسی می‌شوند.

## مدیریت وزن‌های مدل ProPainter
مدل هوش مصنوعی ProPainter به ۳ فایل از پیش‌آموزش‌دیده نیاز دارد:
- `raft-things.pth` (حدود ۲۱ مگابایت)
- `recurrent_flow_completion.pth` (حدود ۲۰ مگابایت)
- `ProPainter.pth` (حدود ۱۵۷ مگابایت)

**مکانیزم ذخیره و بررسی:**
- این وزن‌ها در پوشه `models/` برنامه نگهداری می‌شوند.
- در نخستین انتخاب روش AI Inpaint، برنامه به صورت خودکار وجود فایل‌ها و اندازه معتبر آن‌ها را اعتبارسنجی می‌کند.
- چنانچه فایل‌ها موجود نباشند، پنجره اختصاصی دانلود نمایش داده می‌شود و با رضایت کاربر فایل‌ها دانلود شده و برای اجراهای بعدی ذخیره خواهند شد.

## فعال‌سازی شتاب‌دهی سخت‌افزاری NVIDIA CUDA
برنامه به صورت خودکار از شتاب‌دهی کارت گرافیک در صورت وجود استفاده می‌کند:
- در منوی **Settings** گزینه‌های `Auto`، `NVIDIA GPU (CUDA)` و `CPU` قرار داده شده است.
- اگر گزینه `Auto` انتخاب باشد و درایور و نسخه CUDA نصب باشد، پردازش شبکه عصبی روی GPU اجرا خواهد شد.
- برای نصب نسخه CUDA کتابخانه PyTorch در محیط توسعه، دستور زیر را در CMD اجرا کنید:
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```
- در صورتی که کاربر گزینه NVIDIA GPU را انتخاب کند اما سخت‌افزار یا نسخه PyTorch از CUDA پشتیبانی نکند، پیام خطای شفاف داده شده و برنامه کرش نمی‌کند.

## تنظیمات خروجی و حفظ فایل اصلی
- فایل اصلی کاربر به هیچ عنوان Overwrite نخواهد شد.
- نام ویدیو به شکل خودکار به همراه پسوند `_clean.mp4` تعیین می‌شود؛ اگر چنین فایلی در پوشه خروجی از قبل موجود باشد، به منظور جلوگیری از تخریب اطلاعات نام بعدی به صورت `_clean_1.mp4` و `_clean_2.mp4` تولید می‌شود.
- پوشه خروجی پیش‌فرض در پوشه `output/` برنامه است که در بخش Settings قابل تغییر به هر مسیر دلخواه روی ویندوز می‌باشد.
- تمامی فایل‌های موقت کاری پس از پایان موفق یا لغو پردازش بلافاصله پاکسازی می‌شوند.

## محدودیت‌های فنی AI Inpainting
1. **فضای رنگی ۸ بیتی (SDR)**: معماری یادگیری عمیق ProPainter بر پایه تنسورهای ۸ بیتی RGB آموزش دیده است. ویدیوهای HDR با عمق ۱۰ بیت حین Inpaint به SDR نگاشت می‌شوند و ممکن است داینامیک رنگی ناحیه بازسازی‌شده اندکی تعدیل گردد. برای ویدیوهای حساس HDR، استفاده از متد **Delogo** که مستقیماً در فضای پایپ‌لاین رنگی FFmpeg اجرا می‌شود پیشنهاد می‌گردد.
2. **حرکت‌های بسیار شدید یا محو شدگی (Motion Blur)**: از آنجا که مدل از فریم‌های همسایه برای بازسازی پس‌زمینه استفاده می‌کند، چنانچه واترمارک برای ثانیه‌های متوالی بر روی سوژه‌ای با حرکت به شدت مغشوش و بدون تکرار قرار گیرد، ممکن است جزئیات به شکل نرم بازسازی شوند.
